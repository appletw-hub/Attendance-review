# 差勤自動化審核系統 (Attendance Review System)

專為多部門排班設計的自動化差勤稽核與薪資結算系統。整合 **Gemini AI 多模態 OCR 辨識**、**手寫排班表自動縫合與班別合併**、**代班與加退班時間覆蓋**，以及**打卡鐘 CSV 多維度交叉比對**。

---

## 🌟 系統亮點與功能規格

1. **手寫排班表 AI 辨識（OCR）**
   - 支援一次上傳單張或多張照片，前端 HTML5 Canvas 自動垂直無縫拼接。
   - 動態注入【員工簡寫對照表】Prompt，精準辨識「綽號」並自動替換為正式全名。不在名單內的新人保留原樣。
   - **班別雜訊清理與自動合併**：自動去除「妝」、「髮」、「代班」等標記雜訊（圖一 ➔ 圖二），同人同天排「假日早班＋假日晚班」自動合併為「假日全班」；「早班＋晚班」自動合併為「全班」。
   - 一鍵自動寫入 Google Sheets「排班資料庫」，並支援「一鍵整理歷史班別」按鈕。

2. **代班單 & 加退班單辨識與時間覆蓋**
   - **代班單**：自動識別申請人、代班人與調整後時間，互換值班不扣薪，但會**覆蓋當天排班的應到時間**，避免誤判遲到早退。
   - **加退班單**：自動辨識遲到/應到時間與加班時數（負數時數如 `-4.5` 自動計為早退扣除時數）。

3. **打卡 CSV 批次解析與差勤稽核引擎**
   - 自動掃描打卡鐘 CSV 中包含「工號：」與「姓名：」的區塊，提取 1~31 號最早上班卡與最晚下班卡（支援 Big5 / UTF-8）。
   - **正職員工**：以分鐘為單位計算遲到，遲到金額公式為：`遲到總分鐘數 × 10 元`。
   - **計時 PT 員工**：上班只要晚於預定時間，系統自動統計 `PT 遲到次數 (扣 0.5 小時時薪)`，直接於月結報表呈現供薪資扣抵。
   - **忘卡/缺卡階梯扣假**：
     - 單日僅有單次打卡或無打卡者標記忘卡。
     - 當月忘卡累計達 3 次：扣 1 日休假。
     - 第 4 次起：每次加扣 0.5 日休假（第 4 次扣 1.5 日、第 5 次扣 2.0 日，依此類推）。

4. **一鍵即時備份與差勤資料清除**
   - **💾 備份資料**：支援一鍵即時將當前試算表完整複製備份至指定雲端資料庫（`https://drive.google.com/drive/folders/1uorJ3Ii5u97IF7S2b4m6o5FGMjfFPqLy`），亦支援每日凌晨定時自動備份。
   - **🗑️ 清除資料**：一鍵快速清除動態差勤資料（僅清除「排班資料庫、代班紀錄、加退班紀錄、差勤結算總表」資料列，保留標題列，且業務規則與員工名單完整保留不受影響）。

## 📁 檔案結構說明

- [Code.gs]：Google Apps Script 後端邏輯核心、Gemini API 請求、CSV 區塊解析器與多維度稽核結算演算法。
- [Index.html]：現代化 Web App 響應式儀表板前端（Inter / Noto Sans TC、卡片式設計、多圖拼接、即時篩選、一鍵匯出 CSV）。

## 🚀 部署與設定指引 (5 步驟完成)

### 步驟 1：建立 Google 試算表
1. 至 Google 雲端硬碟新增一個空的 Google 試算表（例如命名為：`差勤自動化審核系統資料庫`）。
2. 點擊頂部選單「**擴充功能**」➔「**Apps Script**」。

### 步驟 2：貼入程式碼
1. 將專案左側的 `程式碼.gs` 內容清空，將 [`Code.gs`] 內容完整貼入。
2. 點擊左側「+」➔「**HTML**」，檔名輸入 `Index`（不需要副檔名），將 [`Index.html`] 內容完整貼入並存檔（Ctrl+S）。

### 步驟 3：設定 Gemini API Key
可使用以下兩種方式之一設定：
- **方式 A（建議）：** 在 Apps Script 介面左側齒輪「**專案設定**」➔「**指令碼屬性 (Script Properties)**」中新增：
  - 屬性名稱：`GEMINI_API_KEY`
  - 屬性值：填入您的 Google AI Studio API Key
- **方式 B：** 於試算表的「`系統設定`」工作表中，將 `GEMINI_API_KEY` 的值填入第 2 列第 B 欄。

### 步驟 4：執行系統初始化
1. 在 Apps Script 編輯器上方函數選取 `initSpreadsheet`，點擊「**執行**」。
2. 首次執行需授權 Google 帳號權限。
3. 執行完成後，Google 試算表將自動建立好所有標準工作表：
   - `員工名單`（建立姓名、職位與綽號簡寫）
   - `排班資料庫`
   - `代班紀錄`
   - `加退班紀錄`
   - `差勤結算總表`
   - `業務規則設定`（填部門、職別、班別時間）
   - `系統設定`
   - `Log_系統日誌`

### 步驟 5：部署為 Web 應用程式
1. 點擊右上角「**部署**」➔「**新增部署**」。
2. 種類選「**網路應用程式 (Web App)**」。
3. 設定：
   - **說明**：差勤自動化審核系統 v1.0
   - **執行身分**：我 (Me)
   - **誰可以存取**：**僅限我自己** 或 **機構內的使用者**（具管理員權限者）
4. 點擊「**部署**」，複製獲得的 **Web 應用程式網址**，即可開始使用！

## ⏰ 設定每日定時備份 (選用)

1. 在 Apps Script 左側點擊「**觸發條件 (Triggers)**（時鐘圖示）」。
2. 點擊右下角「**+ 新增觸發條件**」：
   - 執行的功能：`scheduledDailyBackup`
   - 活動來源：`時間驅動`
   - 觸發條件類型：`每日計時器`
   - 選取一天的時間：例如 `凌晨 2:00 到 3:00`
3. 點擊儲存，系統即會在每日凌晨自動複製當前資料庫作為定時備份。
